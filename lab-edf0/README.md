# Лабораторная работа EDF0

Вариант 18. Учёт выдачи и возврата изданий в библиотеке.

Здесь находятся исходная модель diagrams.net, изображения диаграмм, словарь интерфейсных дуг и отчёт.

Основная функция модели: «Учитывать выдачу и возврат изданий». Модель построена с позиции библиотекаря, который обслуживает читателей и ведёт учёт экземпляров.
