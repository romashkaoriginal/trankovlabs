# Лабораторная работа 1

## Первоначальная настройка Git

В работе создан локальный репозиторий Git и проверены основные состояния файлов:

- untracked - новый файл, который еще не отслеживается;
- staged - файл добавлен в индекс командой `git add`;
- modified - отслеживаемый файл изменен;
- committed - изменения сохранены в истории коммитом.

В репозитории выполнены три коммита:

1. `Initial commit`
2. `Add test row to my_first_file.txt`
3. `Add my_second_file.txt`

Финальная проверка `git status` показала чистую рабочую директорию.
