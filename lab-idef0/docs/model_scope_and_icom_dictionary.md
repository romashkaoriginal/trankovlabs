# Границы модели и словарь ICOM

## Цель модели

Описать учёт выдачи и возврата библиотечных изданий, чтобы определить функции, данные и роли будущей библиотечной информационной системы.

## Точка зрения

Библиотекарь, который обслуживает читателя, оформляет выдачу и возврат экземпляров и контролирует сроки пользования.

## Границы системы

Модель начинается с обращения читателя или возврата экземпляра и заканчивается регистрацией операции, изменением статуса фонда и формированием уведомления или отчёта. Комплектование фонда, закупка изданий и финансовый учёт штрафов в модель не входят.

## Словарь стрелок

| Код | Наименование | Тип | Смысл |
| --- | --- | --- | --- |
| I1 | Запрос читателя | Вход | Обращение читателя на получение конкретного издания. |
| I2 | Возвращённое издание | Вход | Экземпляр, переданный читателем обратно в библиотеку. |
| C1 | Правила библиотеки | Управление | Нормы регистрации читателя, выдачи и возврата. |
| C2 | Каталог фонда | Управление | Сведения об изданиях, экземплярах и их статусе. |
| C3 | Сроки и ограничения | Управление | Допустимые сроки, лимиты и условия ограничения выдачи. |
| O1 | Выданное издание | Выход | Экземпляр, оформленный для передачи читателю. |
| O2 | Статус фонда | Выход | Сведения о доступности и состоянии экземпляра после возврата. |
| O3 | Уведомление | Выход | Сообщение о сроке возврата или просрочке. |
| O4 | Отчёт | Выход | Сводные сведения о выдаче и возврате. |
| M1 | Библиотекарь | Механизм | Сотрудник, выполняющий обслуживание и учёт. |
| M2 | Библиотечная ИС | Механизм | Программа для поиска, регистрации операций и формирования отчётов. |
| M3 | Фонд | Механизм | Набор экземпляров, доступных для выдачи и возврата. |
| W1 | Решение по заявке | Внутренняя | Результат проверки читателя и доступности издания с признаком принятия или отказа. |
| W2 | Запись выдачи | Внутренняя | Карточка операции с читателем, экземпляром и сроком возврата. |
| W3 | Сведения о просрочке | Внутренняя | Результат контроля срока, поступающий в функцию уведомлений и отчётов. При новой заявке наличие просрочки проверяется в учётных данных БИС по правилам C3. |
